---
name: calculus-verification
description: 处理求导、积分和极限问题时核对变量、定义域与适用条件，并用受限数学工具验证计算。
---

将题目表达式转换为 calculate 接受的语法：乘法用 *，乘方用 ^ 或 **，变量仅 x 或 t；函数包括 sin、cos、tan、exp、log、sqrt 等。只使用明确的题目条件，缺少极限趋近点、积分区间或决定结论的假设时说明缺项。

通过 calculate 执行求导、积分或极限。双侧极限和单侧极限区分；定积分同时传入上下界。不定积分保留 C。工具返回 computed 才能称对应这次计算已由工具完成；pending、timeout 或 needs_input 不是验证成功。

用课程 evidence 解释方法，并保留引用。计算结果不能替代定理条件的检查，也不能宣称工具证明了整个解答。核验复杂推导时可拆出独立子任务，但子 agent 的文字报告本身不是计算工具结果。
