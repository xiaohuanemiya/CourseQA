# 五分钟演示脚本

> 历史演示草稿，包含早期审核流程和测试数量，未随每次功能更新重写。当前功能、启动与验收入口以 [项目 README](../README.md) 和 [使用说明](usage.md) 为准。

演示入口：<http://127.0.0.1:8820>。管理员凭据从本地 `.env` 获取，不出现在录屏和展示材料中。

## 演示前准备

准备两个已发布、绑定不同知识范围的应用。正式演示真实生成式问答前，必须配置并实测生成模型。当前两个默认应用是明确标记的证据展示模式，只能据实演示检索、来源、自测与记录。

教材首次审核完成前，不把默认人工示例介绍成用户教材。报告和画面说明使用的知识库、模型及发布版本。

## 0:00–0:40：应用与范围

从应用广场展示“极限与导数研习”和“积分专项研习”，说明同一平台可以创建不同学习应用。打开管理端应用配置，展示绑定知识库、生成模型与 Embedding 模型。

讲解重点：“检索范围由后端读取应用配置确定，每个应用可独立选择模型。”

## 0:40–1:40：知识修订与发布

在演示知识库中选择一个知识条目，对照来源补充适用条件，填写修改依据并保存。展示修改记录，然后发布，等待任务成功。

讲解重点：“修改先进入草稿。公式、条件和关系需要审核，索引构建成功后才切换发布版本。”

演示内容须事先校对，不临时修改真实教材中的公式来制造错误。

## 1:40–2:40：问答与出处

在导数应用询问“可导与连续有什么关系？”，展开引用，展示知识正文、来源与条件。进入积分应用展示其不同的知识图谱或题库范围。

如果已经配置真实生成模型，可追加一个已审核资料无法回答的问题，展示拒答；如果服务仍为演示模式，明确说明此处仅显示检索证据。

## 2:40–3:40：自测与数学判分

按知识点生成一次自测，展示题库不足时返回实际数量。对一道幂函数求导题输入错误答案，再看参考答案和解释。不定积分例题展示积分常数要求。

讲解重点：“确定的错误才判错；工具超时或无法确定时标记待核对。证明题不作为可靠自动判分。”

## 3:40–4:30：个人复习

打开复习计划和错题本，展示本次作答带来的记录、掌握程度估计以及前置知识推荐原因。点击“练习这一点”，进入对应知识点的题目筛选。

讲解重点：“掌握程度是有限作答下的初步估计，无记录的知识标为尚未评估。”

## 4:30–5:00：验证与边界

展示功能验证记录和已完成的实验结果。没有完成的研究结果写明待验证。结束时说明 Podman 启动方式、持久化数据位置和报告入口。

当前可讲述的实测证据是 32 项自动化测试、本地向量模型调用、实际 pgvector 检索和浏览器流程。问答正确率、GraphRAG 收益及学习成绩改善须等正式评价后再陈述。
